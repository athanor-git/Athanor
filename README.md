# Athanor — temple web edition

Offline tools for Thelemic study and practice, published for the members of our temple.

**Open it:** https://athanor-git.github.io/Athanor/

## Install on iPhone
1. Open the address above in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Open it once while online; after that it works offline.

## Install on Android
Open the address in Chrome and choose **Add to Home screen** (or install the Athanor app if you were given it).

## Privacy
The app makes no network requests of its own. Everything you save stays on your device.
